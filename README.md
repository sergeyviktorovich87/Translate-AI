# Translate AI

**v0.2.1-alpha.** Личная Android-оболочка веб-сайта ChatGPT с инструментами перевода русский ↔ китайский. Неофициальное приложение, не связано с OpenAI.

## Главное изменение: одна авторизация
- Одна WebView-сессия для вкладок «Переводчик» и «ChatGPT»; WebView не уничтожается и не перезагружается при переключении.
- Внутреннее всплывающее окно для цепочки Google → OpenAI → ChatGPT, с общими WebView cookies.
- **Удалены ChatAuth, отдельный OAuth и вызовы api.openai.com.** Нет API-ключей, токенов OpenAI в памяти приложения, сервера или дополнительной оплаты API.
- Оба режима используют авторизацию непосредственно на chatgpt.com, а не cookies Chrome.
- Обработка входа через WebView на конкретном устройстве должна быть проверена: Google или OpenAI могут ограничивать встроенные браузеры.

## Переводчик
- Текст и голосовой ввод на русском / китайском.
- Кнопка «Перевести в ChatGPT» формирует понятный запрос и копирует его в буфер обмена.
- Пытается вставить запрос в поле ввода сайта ChatGPT (если сайт изменился, нужно вручную вставить уже скопированный текст).
- Для отправки запроса нажмите кнопку отправки **на сайте ChatGPT**. Ответ виден непосредственно в чате; приложение его не считывает.
- После ответа нажмите **Копировать** на сообщении ChatGPT, затем в нижней панели **📥 Ответ**. Текст появится в отдельном редактируемом поле, откуда его можно копировать и озвучивать.
- «📋 Копировать» копирует текст результата, «🔊 Слушать» озвучивает его системным голосом. Приложение читает буфер обмена только по нажатию на кнопку вставки.
- Сайт сам предоставляет функции копирования и озвучивания, когда они доступны.

## Безопасность
- Не реализовано программное извлечение ответов с сайта, нет JavaScript bridge и чтения cookies.
- WebView ограничивает локальные файлы, HTTP и доступ к камере/микрофону веб-сайта.
- Логи тестовой сборки сохраняют только коды событий: ни тексты, ни URL авторизации, ни cookies/токены.
- Пароли/ключи подписи **не хранить в репозитории**.
- Это альфа. Проверять на Android после сборки; не распространять без независимого аудита.
- Ошибки и ограничения входа могут зависеть от изменений Google/OpenAI.

## Сборка
Workflow: **Actions → Android APK**. После push он собирает debug APK, кладёт в
**dist/Translate-AI-v0.2.1-alpha.apk** и коммитит в приватный репозиторий.
Debug-сборки GitHub Actions могут подписываться разными ключами, тогда требуется удалить старую версию.
Постоянный release-ключ хранится вне репозитория и в workflow сейчас не задействован.

## Почему не через API
Запрос пользователя: личный Translate AI работает через свою подписку на сайте ChatGPT.
Без API нет гарантированного разрешённого интерфейса для автоматической передачи
сгенерированного ответа в нативное поле приложения. Поэтому результат остаётся
на самом сайте, а оболочка добавляет ввод, промпт, копирование и TTS.
Условия OpenAI: https://openai.com/policies/row-terms-of-use/
