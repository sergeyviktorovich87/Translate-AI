# Translate AI 0.4.0-alpha

Нативный Android-переводчик и ИИ-чат. Официальный **Sign in with ChatGPT** для пользователей, которым доступно использование подписки в открытых приложениях. Это независимый, неофициальный клиент.

## Что реализовано
- Единственный вход через OpenAI OAuth + PKCE. Логин происходит в системном браузере один раз при первичном подключении; в самом приложении сайт chatgpt.com не показывается.
- Закрытая безопасная область Android Keystore: зашифрованные OAuth токены, автоматическое обновление с ротацией refresh token.
- Нативный экран «Переводчик»: русский ↔ китайский, пиньинь, ответ прямо в оболочке, копирование, Android TTS и распознавание речи.
- Нативный экран «ИИ-чат»: текстовый диалог и локальный контекст последних 12 сообщений, потоковый ответ прямо внутри приложения.
- Отправка фото в обоих режимах: выбери изображение, приложение уменьшит и перекодирует JPEG (без EXIF/GPS), вложит его как image input в Responses API.
- Предпочтение пользовательской модели из /v1/models, стриминг на /v1/responses с store:false и stream:true.
- Тестовые логи только по кодам событий без содержимого переписки, токенов, фото и кодов OAuth.
- Никаких ChatGPT backend-api, web scraping, инъекций на сайт или серверных посредников.

## Ограничения (важно)
- Для чата и обработки изображений нужен соответствующий доступ аккаунта и поддержка в модели. Возможны 401, 403, 429, 503.
- Responses API в этом режиме **не поддерживает генерацию новых изображений**, а также аудио/видео-вложения; фотографии можно анализировать, переводить текст на них.
- Нативная история диалога пока хранится только в оперативной памяти, до завершения процесса; история ChatGPT.com не импортируется.
- Токены и клиентские регистрации живут только в защищённом хранилище телефона. Это альфа: требуется тест полного OAuth-цикла на реальном устройстве, включая возврат из Chrome.
- При смене debug ключа установка новой версии может потребовать удалить предыдущую. Постоянный релизный ключ не размещать в GitHub.

## Тестовый сценарий
1. Установить APK и подтвердить подключение ChatGPT.
2. Проверить перевод «привет» RU→中文, затем «你好» 中文→RU.
3. Проверить кнопку «🔊 Прослушать» и «Копировать».
4. Перейти в ИИ-чат, отправить вопрос и прикрепить картинку.
5. Закрыть/открыть приложение и убедиться, что повторный вход не нужен.
6. При ошибке экспортировать логи из меню «⋮» и передать только безопасные коды ошибок.
