# Translate AI — 0.3.0-alpha

Личная Android-оболочка сайта ChatGPT для русского ↔ китайского перевода. Неофициальный клиент; не связан с OpenAI.

## Что изменилось в v0.3
- Один вход в ChatGPT и один живой WebView. Сессия Google/OpenAI в оболочке сохранена.
- Новый компактный нативный заголовок с режимами «Переводчик» и «Чат».
- Один ввод текста, голосовой ввод, выбор направления и главная кнопка «Перевести».
- Нажатие «Перевести» подготавливает запрос и пытается **нажать штатную кнопку отправки ChatGPT** в рамках действия пользователя. Если селекторы сайта изменились, пользователь получает понятное сообщение; запрос уже скопирован.
- В режиме переводчика собственное поле ввода сайта ChatGPT скрывается только для оформления; при ошибке отправки или переходе в чат появляется снова.
- Ответ отображается **на веб-странице ChatGPT**, не извлекается программно.
- Для отдельного поля «Результат» сохранён ручной сценарий: копировать ответ в ChatGPT → нажать «📥 Ответ» → копировать или озвучивать.

## Почему пока не отдельная карточка результата
Без разрешённого API и доступа к структуре ответа сайт ChatGPT не обеспечивает стабильного интерфейса для переноса ответов в нативную карточку. Автоматически извлекать output из веб-сервиса запрещают условия OpenAI: https://openai.com/policies/terms-of-use/
Официальная альтернатива: Sign in with ChatGPT с разрешёнными запросами в Responses API (для подходящих аккаунтов) https://developers.openai.com/siwc/token-sharing-open-source

## Безопасность
- Веб-сайт открыт только по HTTPS, локальный доступ к файлам выключен.
- Нет JavaScript-моста для веб-страницы, чтения cookies, токенов, автоматического сбора ответов.
- Автоотправка запускается только по нажатию «Перевести» или после подтверждённого голосового ввода; без фонового опроса.
- Вход Google и OpenAI обрабатывается в WebView с общим cookie jar. Разрешённые хосты ограничены.
- Журнал тестовой сборки: только код события, без текстов запросов, ответов, URL с кодом входа и cookies.
- Ключи подписи и пароли не хранить в GitHub.

## Проверка на Android
1. Установить v0.3, при другой debug-подписи удалить старую.
2. Войти через Google. Проверить, что вкладка «Чат» открывается с той же сессией.
3. В режиме «Переводчик» написать фразу «привет» и нажать единственную кнопку «Перевести».
4. Убедиться, что штатная отправка ChatGPT сработала. Если нет, приложить **логи**, без секретов.
5. Проверить кнопки «📥 Ответ», «📋 Копировать», «🔊 Слушать».
6. Проверить RU→中文, 中文→RU, переключение вкладок и возвращение из внешнего окна входа.

## Сборка
GitHub Actions запускает `:app:assembleDebug` и кладёт APK в `dist/Translate-AI-0.3.0-alpha.apk`. Компиляция не равна проверке на реальном телефоне.
Релизный signing key хранится только вне репозитория и пока не подключён к автоматической сборке.
