# Translate AI

Личный Android-клиент: веб-вкладка ChatGPT + голосовой переводчик **русский ↔ упрощённый китайский**.

**Статус: 0.1 alpha, тестовая версия.** Это не официальный клиент OpenAI. Не распространяйте APK без тестирования и аудита.

## Возможности
- Сайт chatgpt.com во встроенной вкладке; кнопка перехода в браузер, если WebView не поддерживает вход.
- Отдельная вкладка переводчика: распознавание речи Android, перевод, пиньинь, копирование и TTS.
- Добровольная OAuth-авторизация Sign in with ChatGPT для переводов через Responses API (доступность и лимиты зависят от подписки и разрешений).
- Локальная диагностика без текста перевода и токенов, Android Keystore для хранения OAuth-токенов.

## Как получить APK
Готовый APK находится в папке **`dist/Translate-AI-v0.1.1-alpha.apk`**. В приватном репозитории откройте файл и нажмите **Download raw file**. Для следующих сборок используйте **Actions → Android APK**; workflow сам обновляет файл в `dist/`.

### Если сборка не завершилась
Откройте логи **Actions → Android APK**. Из-за исчерпанной квоты GitHub Actions Artifacts APK публикуется прямо в приватном репозитории, а не как Actions Artifact. При необходимости сборку можно запустить вручную.

## Первое использование
1. Установите debug APK на Android (при переустановке другой сборки подпись debug-ключа может измениться).
2. Войдите в ChatGPT во вкладке сайта либо откройте внешний браузер. Cookies сайта и OAuth переводчика отдельны.
3. На вкладке переводчика нажмите «Подключить аккаунт ChatGPT» и предоставьте разрешение на использование подписки, если аккаунт поддерживает такой режим.
4. Проверьте голосовой ввод, перевод в обе стороны, копирование, озвучивание. При проблеме экспортируйте логи теста.

## Безопасность и ограничения
- Никакие логины/пароли не хранить в репозитории и не вводить в сторонние формы.
- Токены остаются на устройстве и защищены Android Keystore. Сетевые обращения выполняются только по HTTPS, кроме локального loopback callback OAuth.
- Веб-странице не предоставляется Javascript bridge и разрешения на микрофон автоматически.
- Вход Google внутри Android WebView может не работать, поэтому предусмотрен системный браузер. Cookies между браузером и WebView не синхронизируются.
- Это альфа: сборка и OAuth на реальном телефоне требуют проверки. Отдельного API-ключа или VPS для архитектуры Sign in with ChatGPT не нужно.

Документация OAuth: https://developers.openai.com/siwc/token-sharing-open-source/

Изменения следует делать через pull requests с автоматической проверкой APK, а не напрямую в пользовательскую базу приложения «Лифт Контроль».

## Вход и ошибка client_id_not_found_in_session
Версия 0.1.1 alpha: в оболочке добавлена кнопка «Сбросить вход», поддержка сторонних cookies и явный переход в системный браузер. Встроенный WebView не гарантирует успешную Google/Apple/Microsoft-авторизацию. Сессия системного браузера не переносится обратно в WebView. Отдельная кнопка подключения ChatGPT для переводов использует OAuth через браузер и не зависит от веб-вкладки. Для диагностики сначала проверьте вход на https://chatgpt.com в Chrome. Обновление содержит тестовые логи событий без паролей, кодов, URL авторизации и токенов.
